LAN YouTube Uploader

This is a private home-network tool. It runs on a Linux computer on the local network and lets the operator send video files to their own YouTube channel using the YouTube Data API.

What it does:

  • Accept a video file and metadata (title, description, tags, category, privacy)
  • Store a draft on the local server
  • Upload that draft to the operator’s YouTube account, either immediately or in a scheduled window
  • Optionally set a custom thumbnail or add the video to a playlist the operator owns

It is not a public product. Only people on the operator’s LAN can open the web UI. There is no public sign-up.

Google account access is used only so this computer can upload videos to the operator’s YouTube channel. See the Privacy Policy.
