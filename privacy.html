Privacy Policy

Last updated: 6 October 2026

This policy describes how LAN YouTube Uploader (“the app”) uses Google user data. The app is a personal tool operated by the owner of this site. It is not offered to the public.

Data we access

When the operator signs in with Google, the app may request YouTube Data API access to:

  • Upload videos to the operator’s YouTube channel
  • Set a custom thumbnail on those videos
  • Add those videos to playlists the operator owns

The app does not read Gmail, Drive, Contacts, or other Google products.

How data is used

Google user data is used only to upload and attach metadata for videos that the operator chose in the app. It is not used for advertising, analytics products, or profiling.

How data is stored

An OAuth token is stored only on the operator’s private Linux server so the app can upload without signing in every time. Video files are stored on that same server until upload finishes (and may be deleted afterward). Tokens and videos are not uploaded to this GitHub Pages site.

Sharing

The app does not sell Google user data and does not share it with third parties. Uploaded videos go only to the operator’s YouTube channel through Google’s YouTube Data API.

Limited use

The app’s use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: the operator of github.com/bonepinyoutube.
